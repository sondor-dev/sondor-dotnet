# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Read it there; it applies in full to every issue, pull request, discussion and any other space where the project is
represented.

In short: be respectful, assume good faith, give and accept feedback gracefully, and keep the discussion about the work.
Harassment, personal attacks and discrimination are not acceptable.

## Reporting

If someone's behaviour is a problem, contact the maintainers privately through the
[sondor-dev](https://github.com/sondor-dev) organisation on GitHub. Reports are treated confidentially.
